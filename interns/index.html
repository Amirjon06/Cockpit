Text-Extraction Module

Turn real documents into clean, study-ready text for the ingestion pipeline.

Semantic Grading Microservice

Grade short and open answers by meaning, not exact string match.

Build a standalone FastAPI service: POST /grade { question, studentAnswer, correctAnswer } → { correct, score 0–1, feedback }. Use local embedding similarity (sentence-transformers, no external key) for short-answer and fill-in-the-blank grading. Tune thresholds, write tests, document the contract. Stretch goal: an optional LLM-judge fallback.
Done when

The service runs locally, returns sensible grades on a test set, and the request/response contract is documented.

Estimate 2.5–3 days Stack Python · FastAPI · sentence-transformers Output own microservice
